# Trip Tally Dashboard

Trip Tally is a small, dependency-free dashboard for seeing upcoming trips, booked costs, planned nights, and itinerary highlights in one place.

## Run locally

Open `index.html` in a browser. No build step or package installation is required.

## Quality checks

```bash
npm test
npm run check
```

The starter data lives in `app.js`, so it is easy to replace with personal plans. Useful follow-up ideas include destination filters, budget progress, departure countdowns, itinerary export, and travel-mode insights.
